# Project skills

## write-swift, apple-design

Sourced from [emilkowalski/skills](https://github.com/emilkowalski/skills) (MIT License, Copyright (c) 2026 Emil Kowalski). Only the two skills relevant to this iOS project were pulled in - the rest of that repo is web/React-frontend and design-tooling specific (animation libraries, Sonner, prototyping workflow) and doesn't apply here.

- **write-swift** - modern Swift guidance (value types, Swift 6 concurrency, protocols/generics, API design, performance, Swift Testing)
- **apple-design** - Apple's fluid-interface motion principles (springs, interruptibility, materials, typography). Written for the web, but the spring vocabulary (damping/response) maps directly onto SwiftUI's own `.spring(response:dampingFraction:)` API, and the materials/typography/reduced-motion sections apply to native UIKit/SwiftUI as-is.
